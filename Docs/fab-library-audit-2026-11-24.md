# Fab library audit (2026-11-24)

Zoe's Fab library has **179 items**, read from fab.com/library with her signed in. About 60 of them are already in
`Content/`. Below are the **unused ones worth bringing in**, grouped by what they're for. The rest are environment
kits we have plenty of, or code plugins we don't need.

**How to add one:**
- Use the **+** button in the Epic launcher (Fab > My Library) and pick **DungeonCrawlerDenver**.
- A **page-with-plus** icon means it's a full sample project. Make it on the D: drive, and Claude copies its assets in.
- Add packs with the editor closed.
